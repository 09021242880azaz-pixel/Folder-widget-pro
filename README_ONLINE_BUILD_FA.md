# ساخت آنلاین APK برای Folder Pro (با گوشی)

این پروژه هنوز APK آماده نیست؛ باید آن را در GitHub Actions بسازید.

## روش پیشنهادی
1. در مرورگر گوشی وارد https://github.com شوید و یک حساب بسازید/وارد شوید.
2. یک مخزن جدید (New repository) با نام `FolderProAndroid` بسازید و آن را Public یا Private قرار دهید.
3. فایل‌های داخل این پوشه پروژه را در مخزن بارگذاری کنید؛ مهم است پوشه‌های `app` و `.github` و فایل‌های Gradle در ریشه مخزن قرار بگیرند، نه اینکه فقط فایل ZIP را بارگذاری کنید.
4. پس از بارگذاری، در مخزن تب **Actions** را باز کنید.
5. اگر از شما خواسته شد، گزینه فعال‌کردن Actions را انتخاب کنید.
6. گردش‌کار **Build Folder Pro APK** را انتخاب کنید و **Run workflow** را بزنید. (اگر خودکار با بارگذاری فایل‌ها اجرا شد، صبر کنید تا تمام شود.)
7. وارد اجرای سبزِ موفق شوید، بخش **Artifacts** را پیدا کنید و `Folder-Pro-debug-APK` را دانلود کنید.
8. ZIP دانلودشده را در گوشی باز کنید؛ داخل آن `app-debug.apk` است. برای نصب، فقط در صورت اطمینان از فایل و منبع آن اقدام کنید.

## نکته‌ها
- این گردش‌کار APK آزمایشی (debug) می‌سازد، نه نسخه منتشرشده با امضای فروشگاهی.
- پروژه برای ساخت به اینترنت در محیط GitHub و چند بسته Android SDK نیاز دارد.
- اگر بارگذاری پوشه‌ها از مرورگر موبایل دشوار بود، بگو در کدام صفحه هستی تا مرحله‌به‌مرحله راهنمایی کنم.
